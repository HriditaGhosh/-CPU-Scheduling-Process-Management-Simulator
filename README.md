# DSA Workbench- CPU Scheduling & Process Management Simulator

**DSA Workbench** is a C++ console-based project that applies fundamental **Data Structures and Algorithms** to a practical CPU scheduling and process management system.

## ✨ Features

* **Process Management** — Add, delete, update and display processes
* **Process Search** — Binary Search & Binary Search Tree
* **Sorting** — Bubble, Selection, Insertion, Merge, Quick & Heap Sort
* **CPU Scheduling**

  * FCFS
  * Round Robin
  * Priority Scheduling
* **Scheduling Analysis** — Waiting Time, Turnaround Time, Completion Time & Gantt Chart
* **Algorithm Comparison** — Compare different scheduling approaches
* **Process Dependencies** — Graph-based dependency management
* **Graph Algorithms** — BFS, DFS & Topological Sort
* **Undo System** — Stack-based operation reversal
* **Process History** — Doubly Linked List for completed processes

## 🧠 Data Structures Used

| Data Structure     | Application          |
| ------------------ | -------------------- |
| Singly Linked List | FCFS Ready Queue     |
| Circular Queue     | Round Robin          |
| Min Heap           | Priority Scheduling  |
| Binary Search Tree | Process Searching    |
| Stack              | Undo Operations      |
| Doubly Linked List | Process History      |
| Graph              | Process Dependencies |
| Vector             | Process Storage      |

## ⚙️ Algorithms

**Searching:** Binary Search, BST Search
**Sorting:** Bubble, Selection, Insertion, Merge, Quick, Heap Sort
**Graph:** BFS, DFS, Topological Sort
**Scheduling:** FCFS, Round Robin, Priority Scheduling

## 🛠️ Tech Stack

* **Language:** C++
* **Standard:** C++11+
* **Interface:** Console / Terminal
* **Build:** Makefile

## 🚀 Run

```bash
g++ -std=c++11 src/*.cpp -Iinclude -o dsa_workbench
./dsa_workbench
```

### Windows

```bash
g++ -std=c++11 src/*.cpp -Iinclude -o dsa_workbench.exe
dsa_workbench.exe
```

## 🎯 Project Goal

The goal of this project is to demonstrate how multiple **Data Structures and Algorithms** can work together to build a functional CPU scheduling and process management system.
